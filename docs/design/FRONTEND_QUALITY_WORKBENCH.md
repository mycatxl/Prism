公开页面已经通过隔离浏览器取图，原始截图与页面信息在 `/tmp/prism-design-references/`。此前 Jina 401 和缺失 web-reader 的问题已通过直接浏览公开页面解决；不能再把“没有实际查看参考”当作完成重构。

## 设计决定

基础色：画布 `#f2f5fb`，数据面 `#ffffff`，正文 `#15213c`，导航 `#111b31`，动作蓝 `#256be6`，辅助文字 `#606e86`。状态色只用于结果，不把全部业务数据染成主题色。

沿用已随项目提供的 Manrope/Sora 与中文系统字体。正文 13–14px，表头 12px，区块标题 16px，页面标题 28px，关键数据 30px；IP 和短数值使用等宽数字。界面以左对齐为主。

深蓝导航固定在左侧，白色工作区保持明确边界，轻透明只用于顶栏和浮层。按钮、列表行和窗口采用不同半径。页面的突出区域是出口质量概况，其他统计与表格保持安静。

```text
导航             工作区路径 / 搜索 / 外观
                 页面标题与主要操作
                 库存 / 健康 / 出口 / 检测状态
                 出口质量概况和来源状态
                 实时流量          连接与会话
                 平台              订阅
```

节点列表把 IP 类型与纯净度参考放入表格主列，详情展开风险原值、代理/VPN/Tor 等标记、来源与有效期。检测失败、未检测、过期和未配置辅助来源各有独立状态。未知不画成零风险。

## 与需求的复核

旧界面的主要问题是大片空白、低对比的青灰色、数据与操作层级接近，且质量字段仅是占位。此次同时调整页面结构和真实数据内容；不以更换主题色代替重构，也不使用与代理工作无关的营销内容。

质量评级保留来源口径：ProxyCheck 原始风险值越低越低风险；AbuseIPDB 的举报置信度单独显示。没有校准依据时不生成“纯净度百分比”，不平均不同来源分数。IPPure 仅提供人工复核入口，并说明需让浏览器使用目标节点。

保留 `/ui` 路由、筛选 URL、详情返回位置、Ctrl+K、Escape、键盘焦点、浅深色与 390px 移动布局。已通过真实后端浏览器回归和桌面/移动、浅深色截图复核，并修正移动卡片布局、订阅内边距、导航图标和登录分区的显示问题。

最终回归记录在 `.local/verification/browser-live.json`，截图在 `web/test-results/screenshots/`。隔离实例已完成一次真实匿名 ProxyCheck 查询并在质量详情显示来源证据；部署后已核对实际服务的 HTML、主资源和质量页面资源与通过验证的构建一致。部署与备份记录见 `SESSION_RECOVERY.md`。
