# Prism 工作台视觉与交互

日期：2026-09-07。沿用个人开源版业务范围，连接真实 Resin API。

视觉方向来自用户指定的 Glassmorphism / macOS Vibrancy。参考页面的 Jina Reader 请求返回 401，备用 Web Reader 未配置，未获取网站正文；以下是对已明确方向的独立实现。

## 色彩与字体

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 工作台背景 | `#edf3f5` | `#0c1820` |
| 数据表面 | `#fcfefe` | `#13262e` |
| 主要文字 | `#19313c` | `#e1eef2` |
| 次要文字 | `#5e7782` | `#9db6c1` |
| 品牌 / 主要操作 | `#087f86` | `#6cd6ca` |
| 次级图表 / 提醒 | `#ad7838` | `#dec084` |

Manrope 用于界面、数据和英文正文，中文采用系统字体；Sora 仅用于 Prism 字标。正文 13–14px，页面标题 25–28px；数值采用等宽数字，避免整段数据标签使用等宽字体。

## 布局

```text
半透明导航    | 页面路径      全局搜索      工具
              | 页面标题                  操作
              | 状态提示 / 查询与筛选
              | 连续数据区域             | 详情抽屉
```

导航与数据面板分层，整个主工作区是一张连续表面。透光、模糊与高光用于导航、工具栏和弹层；表格、输入框、图表使用稳定背景保证对比度。总览保留健康分布、流量和对象列表，加入有真实状态依据的首次导入引导和待确认节点提示。

初稿中的多张独立玻璃指标卡取消，保持现有连续数据分区；避免把透光效果叠到每一行数据。主从详情、搜索参数、返回位置和键盘焦点继续沿用已有行为。

## 行为与验收

- 登录页同时提供语言和外观设置；浏览器禁用存储时仍能打开页面和登录。
- 旧环境变量、主题和会话存储键迁移到 Prism 名称；退出清理新旧敏感会话键。
- 状态区只使用真实 API 数据，质量证据缺失显示未知。
- 动效服务于悬停、展开、关闭等用户动作；遵守减少动态效果和更高对比度偏好。
- 桌面与移动端检查真实登录、导入、节点搜索与详情、平台配置、离线恢复；截图用于视觉复核，不替代操作验收。
