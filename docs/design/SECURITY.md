# 个人开源版安全设计

状态：设计基线，能力待实现与验收。关联：[总设计](../DESIGN.md)、[数据与日志](DATA_AND_LOGGING.md)、[API](API_AND_PRODUCT.md)、[性能与运维](PERFORMANCE_AND_OPERATIONS.md)。

## 1. 信任边界

本项目只有本地管理员及其代理客户端，没有注册用户系统。个人部署仍要保护订阅密钥、管理接口和本机网络；开源发布不能携带真实订阅、令牌或私有日志。

| 对象 | 风险 | 控制 |
|---|---|---|
| 未认证客户端 | 扫描、慢握手、连接耗尽 | 认证前限时、限量，不创建上游连接 |
| 已认证代理客户端 | 凭证泄漏后修改配置、调用任意平台 | 管理与代理凭证分离，限定协议、平台、来源和动作 |
| 订阅文件、标签、节点配置 | 大输入、危险配置、解析错误 | 大小与字段校验、结构化解析、逐条报告 |
| 上游节点 | 不稳定、伪造自述、明文流量观察 | TLS 验证、受控出口探测、质量与健康分开 |
| 外部检测数据 | 未知、冲突、过期、格式变化 | 证据校验、版本、有效期，未知不算通过 |
| 管理页面与自动化任务 | CSRF、命令或 URL 注入 | 统一鉴权、CSRF、参数校验、固定适配器 |
| 数据文件与备份 | secret 泄漏、历史状态误恢复 | 权限、加密、完整备份和恢复校验 |

进程被完全控制或攻击者拥有宿主机 root 时，应用不能保护已经解密在内存中的节点凭证。通过最小权限、资源限制和数据最小化控制影响。

## 2. 监听与凭证

### 2.1 默认部署

- 管理与代理使用独立 listener，默认都绑定 loopback。只开放管理页面不会隐式开放代理端口。
- 局域网/公网绑定需显式配置，必须启用对应凭证。空配置不得自动关闭鉴权。
- 显式 `local_no_auth` 仅允许 loopback 代理 listener；管理写接口仍验证凭证，启动时检查全部 listener。
- 来源 CIDR 是附加限制，不能根据客户端提供的 Header 自行推断来源。
- 公网 HTTP 代理使用 TLS 到网关；CONNECT 到 HTTPS 站点不等于代理认证已加密。裸 SOCKS5 用户密码也不加密，远程使用需配合受支持 TLS 入口或受控隧道。

HTTP 重定向不能补救已经明文发送的密码。远程管理优先通过受控隧道；TLS 终止放在代理前时单独验证 HTTP、CONNECT、SOCKS5，不能假定普通 HTTP 反向代理能透明处理全部协议。

### 2.2 单管理员凭证模型

`prism init` 生成独立的管理员密钥与代理密钥，使用 CSPRNG，secret 至少 256 bit。配置支持 secret 引用，数据库只保存验证摘要和版本；secret 不出现在后续查询响应中。

高熵 secret 使用明确版本、域分隔的 SHA-256 摘要，恒定时间比较。用户自选弱密码不能使用此方式代替口令哈希；本版不建设注册、找回密码和邮箱服务。

代理默认支持一个主密钥，保持 `Platform.Account:secret` 接入形式。自动化切换使用独立动作 token，只允许指定平台/会话；不为换 IP 分发管理员密钥。多代理凭证作为便利能力，必须有明确 key ID 或有界条目数，不能对无限列表逐个慢验证。

`Account` 表示会话，不是管理员身份。认证后由服务端解析并授权 platform ID、session key、协议。代理密钥不得调用管理接口、读取 secret 或添加检测来源。

### 2.3 浏览器会话

浏览器用管理员密钥交换短期服务端会话，默认闲置 30 分钟、最长 12 小时，可配置并主动注销。Cookie 使用 HttpOnly、SameSite 和 HTTPS 下 Secure；仅显式 loopback HTTP 模式允许本地非 Secure cookie。

变更请求验证 Origin 和 CSRF token；默认同源，不允许任意 CORS 源携带凭证。检查 Host 防止针对本地页面的 DNS rebinding。长期密钥不存 localStorage，不出现在浏览器路由、日志和 Referer 中。

提供本地 CLI 轮换管理员密钥，没有未认证远程重置。只信任明确配置的前置代理 IP 对 `Forwarded` 和 `X-Forwarded-*` 的声明。

## 3. 配置发布与撤销

凭证和配置更新经过本地事务，提交后发布不可变快照；API 成功意味着持久化完成且新准入版本生效。若提交成功但内存发布失败，返回可查询的操作失败状态并保守拒绝受影响新流量，不能继续按已撤销版本放行。

每次新请求检查凭证版本和有效期，包括 HTTP keep-alive 上的新请求。会话注册表记录 credential、platform、session generation。撤销成功后拒绝新的旧凭证请求，目标为 1 秒内关闭对应连接；通过共享扫描器或时间桶验证此目标，无需每连接 ticker。

连接登记时再次检查 generation，保证撤销过程中新增的旧连接也被关闭。安全失效不能依赖可丢弃日志或普通异步通知。

质量变化默认影响新路由；显式 close、凭证撤销和禁用入口可以中断现有连接。数据库不可用时拒绝管理变更，已加载且有效的配置可继续代理，不退回匿名模式。

运行期窗口使用单调时钟 deadline，持久化时间用 UTC。明显时钟倒退不得延长证据或凭证有效期；重启后无法确认时间可信时保守处理并提示管理员。

## 4. 目的地址策略

节点服务器、代理目标、订阅下载、GeoIP 和质量查询各自使用 profile；共享校验代码，不共享无限制权限。

默认 public-only 拒绝 loopback、私网、链路本地、组播、未指定、保留地址和云元数据目标。管理员可为自有私网节点、下载源或目标添加 CIDR/域名与端口例外；例外只作用于指定 profile 并审计。允许私网节点不能同时开放全部目标和下载。

### 4.1 解析到拨号

1. 使用标准解析器规范化 scheme、host、port、IDNA、IPv4-mapped IPv6、大小写和末尾点，拒绝歧义数字 IP、控制字符、zone ID 和非法端口。
2. 校验域名、地址和端口策略。下载只允许 HTTP(S)，常规代理端口可配置，不把个人工具硬限制为仅访问网页。
3. 解析全部 A/AAAA，仅拨号已检查通过的具体 IP。重试、重定向重新校验，不能验证域名后再无约束解析一次。
4. HTTP Host 与 TLS SNI/证书校验保持原域名。实际拨号与授权 IP 绑定，不以强制 IP 拨号破坏业务 TLS。
5. 同 IP 线路切换、随机路由、固定节点、反向代理和显式 direct 例外都执行目标检查。

上游强制远端解析域名时，本地 DNS 检查不能证明远端最终 IP。严格模式仅使用经能力矩阵验证、可绑定目标 IP 的 outbound，其他资源明确标注限制。宿主机 egress 规则保护本机网段，不能限制第三方代理所在网段。

工具不对隧道做中间人解密，不能检查 CONNECT/SOCKS5 内每个 HTTPS URL，也不保证下游网站不会再次转发流量。

### 4.2 导入与外部服务

管理员可设置自有 HTTP(S) 探测端点，仍需地址、证书、重定向和大小校验。代理凭证不能设置目标；响应不能触发脚本、插件、本地文件读取或任意 URL 调用。

订阅认证使用 secret 引用。分享 URI 的节点凭证作为敏感配置处理；必要的订阅 query token 保留兼容但默认脱敏。跨源重定向不携带认证。

大小默认值与大文件模式见性能文档。按实际读取字节数限流限量，不信任 Content-Length；限制解压、base64、JSON/YAML 解码后的大小和深度。百万库存通过流式、分批导入实现，不能取消全部输入限制。

质量 key 只送给对应已验证服务，不通过任意节点发送。仅支持查询访问者 IP 的服务使用经审核适配器并验证返回 IP；有敏感 key 时必须明确其受保护的传输和来源边界。多个出口不改变供应商账号配额。

## 5. 协议与资源

保留标准库、sing-box 和已有半关闭、CONNECT 预读字节、WebSocket、取消测试。对 CL/TE、非法 Host、重复长度和 Header 注入增加回归，不自行重写 TLS 或 HTTP 解析核心。

代理认证头转发前移除，业务 Authorization 正常转发但不记明文。反向代理 token 路径仅用于显式 legacy 兼容，默认接口采用独立认证头；日志的 query 和 token 脱敏。

导入只接受受支持 outbound 字段，不执行脚本、读取任意文件、创建监听器或自动启用隐式 direct/detour。协议矩阵标记不能保留的参数，不能忽略 TLS/Reality/认证字段后声称成功。

跳过证书验证的资源默认隔离。管理员可在明确的调试平台使用并审计，不能把开关应用到其他节点。构建失败时回收部分初始化资源。

握手、连接、检测、列表、导出和预览都采用有界资源，流量限速用于保护主机和网络。错误日志与拒绝计数也不能形成日志风暴。

## 6. 数据保护与恢复

节点配置和供应商 secret 使用标准 AEAD，加密记录 key version；安装主密钥为独立 owner-only 文件，不随公开配置导出。主密钥与数据库同时失窃不能提供额外保护。备份支持用户口令加密，并明确恢复所需密钥。

查询仅返回 secret 引用或掩码；原始节点导出是管理员专用动作，审计动作而非内容。临时文件 0600、有限保留，下载令牌短期有效。

显式普通 Account 可展示为会话名；从业务认证 Header 提取的标识默认按安装密钥 HMAC，不存原文。密钥版本变更需迁移索引或明确重置租约，不能静默拆分同一会话。

访问日志默认不存正文、完整认证头和 query。临时诊断限时间和容量，不采集无法解密的隧道内容。检测证据仅保留必要字段。

配置与管理审计使用同库事务，磁盘满则回滚变更。紧急停用可先在内存关闭 listener 并明确报告“未持久化”；重启无法证明配置完整时保持入口关闭，不能把紧急运行期操作称为成功落盘。

## 7. 换 IP 和自动化

换 IP 使用认证 POST、冷却、幂等键和 generation。无替代出口保留原租约并报错。动作 token 只允许指定平台/会话，不携带全局管理权。

浏览器 GET 仅展示状态，真正切换使用 POST/CSRF，避免预取或链接扫描改变 IP。关闭现有连接为明确可见的中断选项。上游重拨通过固定适配器并确认控制范围，不能认为同出口节点都属于同一可控设备。

## 8. 开源与验证

发布构建公开列出协议、格式、标签和平台矩阵。不支持的组合明确报错。默认无遥测、无维护者数据源账号；诊断包先脱敏，用户可以本地检查。

发布前覆盖：代理凭证不能管理资源；各入口授权一致；空密钥和监听范围；轮换及在途连接；DNS 重绑定、重定向、双栈和私网例外；大输入和慢连接；过期证据及视图重建；重复切换与磁盘满；Cookie/CSRF/Host；导出、日志和备份保护。
