# 运维通知、支付网址与节点筛选

## Telegram 运维通知

管理员打开「策略与准入 → 外部运维告警」，填写 Bot token 与个人/群组聊天 ID（或 `@channel`），设置磁盘阈值和重复提醒间隔，再启用并保存。保存后可按「发送测试通知」验证通道。通知配置默认关闭，支持免重启修改。

| 配置字段 | 语义 |
| --- | --- |
| `alert_telegram_enabled` | 外部通道开关，默认 false |
| `alert_telegram_bot_token` | 只用于写入的密钥；PATCH 省略表示保留，空字符串表示移除 |
| `alert_telegram_bot_token_set` | 只读配置状态；GET/PATCH 的 token 字段始终为空 |
| `alert_telegram_chat_id` | 非零数字聊天 ID 或 `@channel` 用户名 |
| `alert_disk_free_percent` | state/cache/log 文件系统可供进程使用的最低空间百分比，1–50，默认 10 |
| `alert_cooldown_minutes` | 同一故障类别的重复提醒间隔，1–1440，默认 15 |

旧配置的零阈值按默认值处理。启用要求 token 与 chat ID 完整；移除 token 时先关闭通道或同时提供替代 token。设置和 `POST /api/v1/system/alerts/test` 要求管理员浏览器会话及 CSRF，自动化密钥不能修改外部通道凭据或发送测试通知。

故障覆盖：

- 磁盘可用空间低于阈值，或无法检查核心存储。
- 持久预留/结算、用量刷新和缓存冲刷返回 SQLite BUSY/LOCKED；扩展错误码也识别。
- 用量播种/补种、周期刷新、计数冲刷失败，持久记账失败或存在未知字节结果。
- 已有节点池变为空，或池内全部启用节点无健康出站；启动预留两分钟，空白新安装不报节点故障。
- 后台任务恢复 panic；缓存持久化失败也独立报告。

监控按分钟扫描；通知走进程内有界队列、单独发送 worker，每次最多三次尝试，瞬时网络错误、429 和 5xx 重试。同类待发送事件去重，持续故障按配置间隔再次提醒。关闭通道后后续发送停止；退出时取消在途发送。重启后未发送事件不保留，持续故障由下一轮监控重新发现。

发送路径不依赖新数据库写入，因此数据库锁或磁盘压力时仍可尝试外发。消息只包含固定故障类别和说明；网络错误、供应商正文、panic 内容、客户身份和带 token 的 URL 不进入通知或发送失败日志。外发配置保存在原系统配置中，数据库和备份仍按密钥存储保护。整机断电或进程硬退出需要外部存活监控。

## 支付通知与返回网址

「运行参数 → 支付网关」中的 `ldc_gateway_url`、`ldc_notify_url` 和 `ldc_return_url` 要求绝对 HTTPS 地址、有效域名和 1–65535 端口，不允许凭据、查询、片段或 EasyPay 分隔符。格式错误在持久化前拒绝。

修改通知/返回网址，或启用 LDC 时，保存响应给出 `payment_url_checks`。检查使用无浏览器 Cookie、无 Authorization、无签名参数的 HEAD，请求总预算四秒，验证公开 DNS、HTTPS 和响应状态；不跟随重定向、不使用环境 HTTP 代理，并在实际拨号前拒绝私网/回环/元数据地址，覆盖 DNS 重绑定。

404、访问控制、重定向、网络/证书失败、DNS 失败或非标准通知路径会在页面显示警告。合法网址即使网络检查失败仍保存，便于运营者随后修复 DNS 或入口；警告不会静默消失在成功提示中。200 只表示网络可达，400/405 还需确认签名和方法。真实小额付款及账目核对仍是支付验收。

标准通知路径是 `/api/v1/public/ldc/notify`，支持 GET/POST 验签。返回页面可用 `/ui/me/deposit`。网址留空时，付款请求的访问域名决定生成地址，保存会提示核实公开 Host；反代应固定正确 Host。更换回调域名/路径时，应为尚未完成的订单保留旧入口。

TRON USDT/TRX 使用链上轮询、地址校验和订单窗口，没有可编辑的支付回调 URL。商户密钥和 TronGrid API key 继续遵守 `*_key_set` 不回显规则，旧订单按原验签凭据和金额条件结算。

## 节点筛选契约

节点主筛选提供协议、所有订阅来源（分页从 `listSubscriptions` 读取，包括禁用来源）、出口探测国家/地区、常用地区按钮、参考延迟区间和出口测得状态。路由平台筛选继续表示平台候选池，不等于服务解锁。

| API 参数 | 语义 |
| --- | --- |
| `protocol` | 小写协议标识，常用协议在主筛选；合法扩展标识可继续通过 URL 使用 |
| `subscription_id` | 来源 UUID，与平台和其他条件取交集 |
| `region` | 两位出口地区码，不区分大小写；无需情报评分 |
| `country` | 已有有效情报的国家；在高级筛选中，与 `region` 同时生效 |
| `latency_min` | 参考延迟下限，毫秒，包含边界 |
| `latency_max` | 参考延迟上限，毫秒，不包含边界 |
| `has_egress_ip` | true 为已测得出口地址，false 为未测得 |

延迟使用当前配置参考域名的平均 EWMA，与列表展示口径一致；未测得或非正延迟不匹配区间。边界要求有限数值 0–3,600,000 ms，下限必须小于上限。快捷区间为优质 `<150 ms`、可用 `<300 ms`、较慢 `≥300 ms`、全部；高级筛选可输入自定义区间。

列表、导出及保存的导出筛选共用校验和语义；统计数量按当前交集计算。选择「无出口 IP」清除精确出口地址，填写精确地址清除冲突的「无出口」条件。更改筛选或区间清除分页游标；活动标签显示来源名和实际边界，每项可独立移除，全部清除保留视图、页大小及排序。

批量情报不能复现延迟、出口测得状态等筛选时，按钮会禁用并说明原因，避免把当前列表错误扩大为全池任务。已有平台与订阅同时选择的交集同样不会转换成批量任务的并集。

部署入口及来源 IP 边界见 [INGRESS.md](INGRESS.md)，容量预算与基准证据见 [CAPACITY.md](CAPACITY.md)。
