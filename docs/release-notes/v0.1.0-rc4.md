# Prism v0.1.0-rc4 发布说明（预发布）

**中文摘要**：v0.1.0-rc4 是 v0.1.0-rc3 之后的**推荐预发布版本**——管理面板换了一整套视觉世界（暗夜玻璃 + Bento 看板），
并按操作者给的参考图在 **1536×1024** 上做逐像素复刻（26 项探针全部落回容差内）；"可见文案必须进词典"从一句话变成能失败的
门禁（补 38 条缺口）；登录页不再靠 401 推断"这个部署要不要令牌"（新增 `/ui/session.json`，两种部署模式下登录页都零 console 错误）。
内核与依赖没有任何变化：`go.mod` / `go.sum` 与 rc3 **逐字节相同**（sing-box **v1.14.2**，sing 固定在同一 commit），
本版**没有新增数据库迁移**。本文件的每一条都来自 git 历史、代码与本机实测；凡是没能证实的都不写。

> **为什么是 rc4**：rc3 之后 main 上累积了 **11 个提交**，包含面板视觉换代、参考图复刻与三项修正。rc3 的二进制与镜像里没有这些内容，
> 用它部署等于用 11 个提交之前的界面；rc4 的意义就是让"下载 release 二进制 / 拉镜像"这条腿与 main 一致。
>
> **已经验证的**：CI 在干净 runner 上六步全绿（`make web` → 安装 golangci-lint v2.14.0 → `make verify` →
> `make lint-go` → `make backend` → `make smoke`）；本机 `make test-web`（含 37 项面板测试、`tsc`、100 组对比度、组件库规则）、
> `make test-slop`（反模式检测器，0 命中）、`go test ./internal/api/... ./internal/docsguard/...`、
> `make lint-go`（8 个真实构建标签，**0 issues**）；1:1 复刻验收跑的是**真实二进制**（`make web` + `make backend` 后启动
> `bin/prism`，登录后 1536×1024 暗色）——**26/26 探针在容差内**、无横向滚动、控制台无错误；登录页在"受保护"与"匿名"两种
> 部署形态下都实测零 console 错误、零 4xx/5xx。
>
> **尚未验证的**：真实服务器上的多日长跑、公网 TLS 证书链、生产负载特征（三条自 rc2 结转，只能在真机上做）；
> 容器**运行**验证仍是 rc2 那次的人工结论（CI 里没有 docker 步骤，本版发布流程只证明镜像能构建与拉取）。

**事实来源**：本版本的内容是 `v0.1.0-rc3` 之后的全部 11 个提交（见文末「本轮提交」），44 个文件 +3461/−1181。

## 1. 本版要点（相对 rc3）

### 1.1 管理面板换了一整套视觉世界

- **视觉世界重建**（`7000e96`）：设计令牌、玻璃层（`rgba(255,255,255,.045)` + `blur(14px) saturate(1.4)`）、
  248/64 两种宽度的导航栏、暗色优先的夜空底色；规范重写进根目录 `DESIGN.md`。
- **按参考图复刻 1536×1024 看板**（`a242089`）：参考图只有 PNG，而本环境的 agent 都没有图像通道，
  所以先把它变成数字（颜色普查、发丝线网格、逐卡文字度量、圆角内缩、KPI 不等宽 206/188/186/173），再用同一套探针
  跑我方真实二进制渲染——**保真度是数字，不是观感**。九个内容槽对十一个真实区块，因此有**两处折叠**：实例健康（读数在 rail
  状态块里）与节点延迟分布（hero 带窗口延迟读数）；两者在 1536 以下都完整渲染，折叠是断点决策而不是删面板。
- **hero 光场按实测补齐**（`e9bced5`）：四个 radial stop（`#47609f` / `#31497f` / `#2b4172` + 广域 `#1b2a53`）只落在
  1255×233 的带内，A 槽底色差从 **23.8 降到 4.3**。
- **H 卡行距对齐，并撤销一条早期误判**（`c9d568a`）：参考图里"H 卡内嵌的 101×151 地区瓦片"其实不是瓦片——
  那里的墨迹越过 x1237、H 的底色贯穿其上、没有任何边框把它隔开，它就是 H 自己的行（动作 + 目标两行，时间右对齐）。
  于是删掉那条从不生效的 `.wb-slot-k` 规则，改成按实测把行距做成 **54px**（原先 44px 让列表比参考图早结束约 100px）：
  五行现在落在 y659/713/767/821/875，参考图是 662/715/769/823/878（恒定 3px 偏移，与其余列一致）。
- **逐槽位底色差（实测，越小越像）**：A 4.3 / B 3.2 / C 7.0 / D 2.5 / E 11.8 / F 8.4 / G1 6.7 / G2 2.7 / G3 2.5 /
  G4 5.1 / H 2.9 / I 1.8 / J 18.6 / K 6.2，全局 MAE 13.9。J 的差是**内容**（我方渲染真实分布，参考图是示例数据），
  E/F 的差是玻璃叠层的亮度；这些残差与理由都写进根目录 `DESIGN.md`，没有藏起来。

### 1.2 新增的三道门禁与修正

1. **可见文案必须进词典**（`570b712`）：`tests/i18n-coverage.test.mjs` 把每个 `t("…")` 字面量与词典对账。
   这里是"中文即键"（`buildZhTranslations()` 把每个键映射成自己），所以缺条目在默认语言下完全看不出来，只在英文里露出中文——
   实测补了 **38 条**，其中 **30 条**集中在平台节点准入条件表单（面板重建没碰过的页面，也因此漂移）。
   扫描器要同时躲开三个坑：不带引号的中文键（`视图: "View"` 合法，中日韩字符是标识符字符）、字符串里的 URL
   （`t("http://user:pass@host")` 被"剥注释"误吃）、以及函数名以 `t` 结尾（`default("http:…")`）。负向对照：
   注入一条未登记的文案，测试变红并列出它。
2. **登录页不再靠 401 推断**（`03a7a1f`）：登录页原先无凭证探测 `GET /api/v1/system/info`，把 401 读成"开了鉴权"。
   答案对，仪器错——浏览器自己会把那条 401 记成 console 错误，于是**每一个受保护部署的第一屏都必然带噪声**。
   现在 `/ui/session.json` 直接回答 `{"auth_required": bool}`（由 SPA 处理器按部署自身的管理员令牌生成），登录页与受保护路由
   都在拿到令牌之前问它；`/ui/` 本来就被接入点的 `allow_management` 约束，所以没有扩大可达面。`TestWebUISessionModeAnswersBothWays`
   同时锁住两个取值（永远答 `true` 的处理器会把匿名部署送进一个不可能通过的登录表单）；把处理器改成恒定 `true`
   实测变红（`auth_required=false: reported true`），改回即绿。
3. **反模式门禁的两处修正**（`32d61f3`、`f27e69c`）：检测器报告里"整文件级"的条目过去被解析器漏掉——那正是
   一类"看起来干净其实没查"的假绿，现在它会红；hero 光晕的豁免也从"按文件名放行"改成**自维持**：只有上报的颜色确实出现在
   hero 带的规则里才成立，改掉带内的 stop 或挪走规则，豁免自己失效（负向对照：把带规则改名 → 门禁立刻红，改回 → 绿）。

### 1.3 界面之外几乎没有改动

`DESIGN.md`、`internal/api/server.go`、`internal/api/webui.go`、`internal/api/webui_test.go` 是本版唯一不在面板目录下的改动，
全部服务于 `/ui/session.json` 那一个端点。没有配置键增删，没有环境变量改名。

## 2. 升级步骤

### 2.1 从 Prism 旧版本（含 rc3）升级

数据目录（`PRISM_STATE_DIR` / `PRISM_CACHE_DIR` / `PRISM_LOG_DIR`）保持不变；**本版没有新增迁移**。

```sh
# 1. 先快照（在线，VACUUM INTO，无需停机窗口）
/opt/prism/scripts/prism-backup.sh backup --out /var/backups/prism --keep 7

# 2. 停服务
sudo systemctl stop prism

# 3. 更新二进制（源码方式；也可以直接替换 bin/prism）
cd /opt/prism && git pull && make build

# 4. 换端口/数据目录时才需要重跑部署脚本（它保留已有 .env）
sudo ./scripts/deploy.sh

# 5. 启动并确认
sudo systemctl start prism
./bin/prism check-config          # 有效配置，密钥打码
./bin/prism version               # 版本 / 提交 / 构建标签
```

- **面板变化对运维是零操作**：浏览器强刷一次即可（静态资源带内容哈希，旧缓存不会与新后端错配）。
- **新增一个无需鉴权的路径 `/ui/session.json`**：它在 `/ui/` 之下，受接入点 `allow_management` 与 `PRISM_ADMIN_LISTEN`
  的既有约束，不改变任何鉴权边界。
- 端口/接入点有变化时重新检查接入点的 `allow_management`：管理面、`/ui`、`/sub` 都受它约束。
- 容器方式：`docker-compose.yml.example` 的镜像标签已固定到 `0.1.0-rc4`；`latest` 只在非预发布版本发布，
  所以在每个版本都是 `-rc` 的当下它并不存在（照抄示例时请用固定版本号）。

## 3. 已知限制

这些是本版本**确认存在**的边界，不是待办清单（已在代码/文档中核实）：

1. **上游 sing 的 `(*CachedConn)` 数据竞争仍在，本版不掩盖它**（同上一条的形态与栈）：纯上游复现器在 `-race` 下报 8 次，
   Prism 侧零帧；pin 住的 sing 与上游 `dev`/`main`/`stable` 该段逐字节相同。触发条件是 `GOMAXPROCS=2` 下 `-count=100`
   约 1/100，CI 命中即重跑。要根治需给上游提 PR（对外动作，等操作者点头）。
2. **参考图复刻有两处折叠、三处真实残差**：折叠（实例健康、节点延迟分布）与残差（J 的内容差、E/F 的玻璃亮度差，
   以及 K 区域按测试夹具的数据差异）都记在 `DESIGN.md` 的 1536 板一节里，连同它们的数值。
3. **mihomo 不引入带来的协议缺口**：SSR 存量、Snell v1–v3、kcptun、VLESS XHTTP 等只能被导入并在解析报告里以
   `ENGINE_NOT_BUILT` 说明；重建条件见 `docs/ENGINE_DECISIONS.md` D-1。
4. **质量与情报数据源需要自备离线库**（DB-IP Lite / MaxMind GeoLite2 / IPinfo Lite 不随包分发）。
5. **mihomo 导出的 `anytls` 需要较新的 mihomo**（v1.19.2 报 `unsupport proxy type: anytls`，v1.19.31 正常），见 D-4。
6. **两个验证目标只在本地跑**：`make test-ui`（需要 Playwright 的 Chromium）与 `make test-slop`（需要外部检测器引擎）；
   CI 覆盖的是源码级门禁。`make verify` 覆盖类型、对比度、组件库规则、面板配置测试与 i18n 覆盖。
7. **容器运行时验证仍只有 rc2 那次人工结论**。
