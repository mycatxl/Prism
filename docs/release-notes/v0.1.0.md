# Prism v0.1.0

第一个正式版本。Prism 是给程序调用的中转代理池：多订阅聚合、粘性租约、按平台调度，流量经 Prism 转发到 sing-box 出站节点。

## 相比 rc5 的变化（rc6 未单独发布，已并入本版）

- 安全默认值收紧：
  - 订阅与 GeoIP 下载拒绝访问回环、私网与云元数据地址（含重定向，按连接时解析的 IP 判断）。需要从内网拉订阅时设 `PRISM_RESOURCE_FETCH_ALLOW_PRIVATE=true`。
  - `PRISM_DENY_PRIVATE_NODES`、`PRISM_DIRECT_DENY_PRIVATE` 默认开启。
  - `PRISM_PROXY_AUTH_FAIL_LIMIT` 默认每 IP 每分钟 30 次。
  - compose 示例只在 127.0.0.1 上暴露端口。
- 移除公开免费节点采集器 `public-source-sync`（含无鉴权 `/sub`），发行包只含 `prism`。
- 移除订阅导出，保留管理员“导出节点”。
- 控制台重构为浅色优先的“潟湖青”风格；`GET /api/v1/system/info` 增加面板自身出口位置，供地图画流向。
- naive 节点在导入时就报 `ENGINE_NOT_BUILT`。
- CI 新增 Playwright 浏览器回归（`make test-ui`）和容器运行验证（镜像构建、运行、重启、镜像内二进制跑全量 smoke）。
- 下载体积上限配置生效；订阅返回空结果时不再清空节点池。

## 升级提示

- 启动时自动执行一个迁移（删除订阅导出相关表），无需手动操作；替换二进制或镜像后重启，浏览器强刷一次。compose 镜像标签改为 `0.1.0`。

- 如果节点或订阅确实在内网，升级后需显式关闭对应的地址策略。
- 只使用 sing-box 单引擎，SSR/Mieru/VLESS-XHTTP/Snell v1–v3 报 `ENGINE_NOT_BUILT`。

## 已知限制

- 上游 sing 库 `CachedConn` 偶发数据竞争（仅 `-race` 测试可见）。
- 真实服务器多日长跑、公网 TLS 证书链尚未验证。
