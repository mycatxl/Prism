# Prism v0.1.0

First stable release.

## Highlights

- Safer defaults: private and metadata addresses are blocked for subscription downloads, nodes and direct dials; proxy auth failures are rate-limited (30/min/IP).
- Removed the public free-node collector (`public-source-sync`) and subscription export.
- Redesigned, light-first console.

## Upgrading

If your subscriptions or nodes live on a private network, set `PRISM_RESOURCE_FETCH_ALLOW_PRIVATE=true` and/or `PRISM_DENY_PRIVATE_NODES=false`.
