# Prism v0.1.0-rc6 发布说明（预发布）

**中文摘要**：rc6 是控制台视觉的整体重做（玻璃质感 Bento 看板、扁平全球流量图、重建的仪表盘图表、浅色主题可读性），
加上一个后端补充：`GET /api/v1/system/info` 现在带上**面板自身的出口位置**（best effort、带缓存），
让看板地图能画出"从面板流向节点地区"的流量。更重要的是验证面的补齐：**CI 现在会跑 Playwright 浏览器回归
（`make test-ui`）和容器运行验证**（构建镜像 → `docker run` → 健康检查 / UI / API 鉴权 / 降权用户 / 重启 →
用镜像里的二进制跑完整 `scripts/smoke.sh`）。rc5 里"只在本地跑"和"容器运行验证只有 rc2 人工结论"这两条已知限制因此关闭。
`go.mod` / `go.sum` 与 rc5 相同（sing-box **v1.14.2**），本版**没有新增数据库迁移**。

> **已经验证的**：本机 `make web` + `make backend` 后 `make test-ui` **10/10** 通过。
> CI 在干净 runner 上两个作业全绿（run `37921508685`，提交 `40cd548`）：Verify（原有六步 + Playwright 浏览器回归）与 Container（镜像构建、运行、重启、镜像内二进制跑全量 smoke）。
>
> **尚未验证的**：真实服务器多日长跑、公网 TLS 证书链、生产负载特征（自 rc2 结转，只能在真机上做）。

**事实来源**：`v0.1.0-rc5`（`2979b99`）之后的 15 个提交，65 个文件 +4205/−3825，外加本版的 CI 改动。

## 1. 本版要点（相对 rc5）

### 1.1 控制台视觉重做
- 统一的玻璃质感 Bento 网格替代固定复刻画布，看板按窗口响应式排布（`2499ba9`、`4921022`、`52a7729`）。
- 3D 出口地球换成扁平全球流量图，流向从面板出口画到节点地区（`827c719`、`6d42c1b`）。
- 仪表盘可视化重建、卡片层级统一（`89d6c06`、`b92d547`、`58c6266`、`d6a1535`）。
- 浅色主题可读性修正（`e70174e`、`0737de4`）；节点过滤器紧凑化（`62aa127`）；hero 加上刷新与添加订阅按钮（`ecd8aea`）。
- 修复：畸形节点条目不再让节点池崩溃（`2f25575`，并加入浏览器回归项）。

### 1.2 面板出口自测（后端）
- 新增 `internal/service/panel_egress.go`：面板定期观测自身出口地区/IP，结果缓存，失败不影响接口。
- `GET /api/v1/system/info` 增加对应字段；**没有新增端点**，鉴权边界不变。

### 1.3 CI 补齐
- `Verify` 作业新增：安装 Playwright Chromium → `make test-ui`。
- 新增 `Container` 作业：`docker build` → 按 `docker-compose.yml.example` 的方式 `docker run`（命名卷、随机令牌）→
  检查 `/healthz`、UI、API 401/200、进程以 `prism` 用户运行 → `docker restart` 后再次健康 →
  `docker cp` 出镜像内二进制跑 `scripts/smoke.sh` 全量检查。

## 2. 升级
- 二进制或镜像替换后重启即可；浏览器强刷一次。
- `docker-compose.yml.example` 的镜像标签发布时改到 `0.1.0-rc6`。

## 3. 已知限制
1. 上游 sing 的 `(*CachedConn)` 数据竞争仍在（同 rc5 §3.1）。
2. mihomo 不引入带来的协议缺口（`docs/ENGINE_DECISIONS.md` D-1）；`anytls` 导出需较新 mihomo（D-4）。
3. 质量与情报数据源需自备离线库。
4. `make test-slop` 仍只在本地跑（需要外部检测器引擎）。
5. 面板出口自测依赖面板能访问外网；离线环境下该字段为空，地图不画流向。
