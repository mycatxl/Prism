## 仍存在的边界与后续要求

1. **数据与日志并未完成加密迁移。** 原始节点配置、租约账户、旧日志及备份仍可能含 secret。HMAC 当前只应用于新请求日志，代理密钥轮换会改变未来日志标识，不迁移路由身份。开启正文详情后正文仍是原文；URL 路径也可能含敏感业务内容。现阶段不要把数据库或日志作为已全面脱敏的诊断包分享。
2. **反向代理仍使用 legacy URL token。** 尚未实现独立认证头入口及 URL token 迁移。把凭证放入浏览器访问的反代 URL 会向页面本身暴露它。2260 仍有兼容 UI/API；管理登录应使用独立的 1262。不要在 2260 登录管理 UI 后，在同源同标签页浏览不可信反代 HTML。
3. **浏览器仍使用 Bearer/sessionStorage。** 旧存储迁移与受限存储回退不等于 HttpOnly 服务端会话；会话到期、Cookie/CSRF/Host 策略、密钥轮换和在途撤销仍待设计实施。当前管理 API 不依赖自动发送的 Cookie 鉴权。
4. **入口隔离有明确配置前提。** 正常 CLI 启动拒绝空令牌，底层兼容构造器仍保留空 token 分支。管理员与代理令牌必须不同；`init` 独立生成，手工配置相同值尚未被拒绝。代理 token 可调用既有的受限 inherit-lease 动作，不能据此调用通用管理 API。
5. **完整地址策略与库存资源边界尚未落地。** public-only/CIDR 例外、解析与实际拨号绑定、供应商 secret 隔离、受支持 outbound 参数白名单、有界 Outbound 热缓存及持久库存分层仍需后续实现。响应大小上限和 32 个默认探测 worker 不构成完整 SSRF 或资源耗尽防护。
6. **发行和容量验收未完成。** 未做公网渗透、全协议真实上游互通、跨系统构建、磁盘满/崩溃恢复矩阵或 10 万/30 万节点容量测试。许可证主声明与关键上游原文已保留，完整发行依赖许可清单仍需生成。根目录 `.git` 不可用，尚未创建提交或发布版本。

IP 质量来源、住宅/机房识别、信誉与黑名单证据、质量准入、同出口优先级及 rotate 属于后续业务实施计划，不能用本轮安全修复和现有健康探测替代。
