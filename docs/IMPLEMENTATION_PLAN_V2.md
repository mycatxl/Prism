# 个人开源版实施计划

目标：在不整体重写 Resin 代理核心的前提下，交付一个可导入、可检测、可筛选、可切换和可安全运行的个人开源版本。

## M0：基线与许可证

- 固定 Resin 参考提交、Go、sing-box 和构建标签，复制到 Prism 模块而不是继续把参考目录当运行代码。
- 运行现有核心测试，补 `go test -race`、完整构建和协议构建矩阵。
- 建立依赖、许可证、secret 扫描和可复现构建；核对 Resin MIT 与 sing-box GPL-3.0-or-later 的发行义务。
- 定义配置版本、数据库目录、日志留存和默认 loopback 绑定。
- 固定管理面板默认入口为 `127.0.0.1:1262`，后端 API/代理端口独立配置（当前默认 2260）。面板环境变量与后端 token 各自读取，不将 token 放入公开前端配置。

验收：参考核心测试通过；没有公开 secret；启动配置和许可证文件可审查；代理/管理 listener 默认安全。

## M1：可运行代理内核

- 迁移 `proxy`、`outbound`、`routing`、`topology`、`state`、`requestlog` 和必要 API。
- 保留 HTTP forward、CONNECT、SOCKS5 CONNECT、reverse/WebSocket、订阅解析、节点去重、P2C、租约和恢复。
- 加入单管理员凭证、管理/代理 listener 分离、目标地址策略和输入大小限制。
- 先不加入质量供应商查询；用健康、出口、延迟和标签验证最小闭环。

验收：真实或本地模拟节点可导入并通过三类入口代理；重启恢复；凭证隔离；既有 Resin 回归测试及新增安全测试通过。

## M2：出口分组与质量检测

- 添加出口观测 generation 和 `IP -> egress group` 索引。
- 保留 Resin 健康探测，新增独立 inspection 队列、每节点/每来源限流、超时、退避和任务持久化。
- 实现基础出口分类、GeoIP、可插拔信誉 provider、名单结果和评分区间；默认提供不依赖付费服务的基础模式。
- 结果按 IP 复用，健康仍按节点独立判断；旧出口异步结果不能覆盖新出口。

验收：同 IP 线路共享质量查询但可独立故障切换；出口变更会重新评估；查询失败、未知、过期和冲突不会误标为合格；队列满不阻塞代理。

## M3：Platform 标签与路由升级

- 原样继承 ANY/MUST/MUST_NOT 语义，保存时编译，增量更新平台视图。
- 添加地区、IP 类型、分数区间、名单、证据年龄、手动分类、订阅范围和优先级规则。
- 先质量硬准入，再按出口组负载/延迟 P2C；组内按优先级故障切换。
- 添加平台预览、排除原因、合格线路/独立 IP 数和规则版本。

验收：多标签不跨 Tag 拼接；标签、订阅、质量、健康和策略变更在并发请求中最终遵守最新版本；无合格节点明确失败。

## M4：日志、管理页面与切换

- 完成结构化访问日志、检测日志、审计、指标和滚动留存。
- 实现订阅/导入、节点池、出口组、平台、检测、日志和设置页面；不显示 secret。
- 实现手动 rotate、定时 rotate、同 IP 线路优先级、固定端口/会话（按需要）。
- 加入备份、恢复、导出、密钥轮换和紧急停用。

验收：日志能解释一次路由和一次检测；普通日志丢弃不影响代理；rotate 的幂等、旧 IP 排除、无替代出口和 keep/close 行为正确；备份能恢复。

## M5：容量与开源发布

- 建立 10 万、50 万、100 万库存节点的分批导入和冷库存测试；单独测试 1 千、1 万活跃检测线路。
- 测量内存、FD、GC、SQLite/WAL、启动恢复、平台重建、检测积压和代理 p99。
- 按结果确定默认 worker、热 Outbound 上限、日志留存和是否需要分库；不按行数自动引入外部数据库。
- 完成 fuzz、race、依赖扫描、许可证、SBOM、构建产物、文档和漏洞报告流程。

验收：报告给出实际硬件和边界；已知越权、SSRF、secret 泄漏、数据损坏、无界内存和协议回归为零；发布包可由第三方复现或验证。

## 明确不做的首版工作

不实现用户注册、SaaS、多租户、套餐、支付、订单、商业额度、分布式控制面、强制 PostgreSQL、Redis/Kafka/etcd、rpure 合并、代理协议自研和默认 UDP ASSOCIATE。未来若范围改变，必须新建 ADR 和数据迁移设计，不在个人版中隐式加入。
