# Prism 前端设计规范

这份文档是重写面板时唯一的依据。任何页面的取舍都以它为准；与它冲突的旧类名一律作废。

## 概念

**纸上的仪表盘。** 主体是网络出口——流量从哪出去、经过哪个地址、那个地址有多干净。所以界面借用了**在日光下读数的测量仪器**的视觉语言：冷调纸面、发丝细线、等宽表格数字，以及**只有一个强对比色**，留给需要注意的东西。

结构由**细线和对齐**承担，不由卡片和阴影承担。**没有深色模式**：这是台台式仪器，数值是被读的，不是被"在暗处盯着"的。

## 令牌

全部定义在 `src/styles/design.css` 的 `@theme` 里，用 Tailwind 工具类消费。

### 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `paper` | `#f3f5f2` | 底色。冷调纸白，**刻意不是奶油色** |
| `paper-sunk` | `#e8ece7` | 凹陷区：表头、井、分栏的下沉半边 |
| `paper-raised` | `#fbfcfa` | 抬起区：真正浮在纸面上的少数地方 |
| `rule` | `#d3dbd4` | 发丝细线（默认边框色） |
| `rule-strong` | `#b6c1b9` | 需要更明确的线 |
| `ink` | `#101713` | 正文。带绿调的近黑 |
| `ink-soft` | `#57635c` | 次级文字 |
| `ink-faint` | `#8b968f` | 三级文字、单位、占位 |
| `signal` / `signal-deep` / `signal-wash` | `#0b7a6e` / `#064e47` / `#dfeeea` | 健康、主操作、状态良好 |
| `live` / `live-wash` | `#0e7490` / `#ddedf3` | 在途、排队、进行中 |
| `warn` / `warn-wash` | `#9a6106` / `#f6ecd6` | 降级、过期、需要看一眼 |
| `alert` / `alert-wash` | `#c2410c` / `#fae8de` | 风险、失败、被阻断 |

用法：`bg-paper`、`text-ink-soft`、`border-rule`、`bg-signal-wash`、`text-signal-deep`。

**克制**：`alert` 是唯一强对比色。一屏里它出现的次数应当很少，否则它就不再是信号。

### 字体

| 令牌 | 字体 | 用途 |
|---|---|---|
| `font-sans` | **IBM Plex Sans** | 所有界面文字 |
| `font-mono` | **IBM Plex Mono** | **所有被当作数据读的值**：IP、哈希、延迟、计数、ASN、时间戳 |

同一字体血统，两种明确分工。自托管（`@fontsource`），保持单文件部署。

### 字号

`text-2xs` 11 · `text-xs` 12 · `text-sm` 13 · `text-base` 14 · `text-lg` 16 · `text-xl` 22 · `text-2xl` 28 · `text-3xl` 38 · `text-4xl` 52

大数字（`text-3xl`/`text-4xl`）只给仪器读数，不给卡片标题。

### 几何

- `rounded-control`（2px）：按钮、输入框、下拉
- `rounded-panel`（3px）：面板
- **直角**：表格、细线、结构
- **全圆**：只有状态徽标（`pill`）

三种半径各有分工，不是"哪里都一个圆角"。

## 组件库

`src/components/ui/` 是唯一允许的组件来源。禁止自己写新的按钮/徽标/表格样式。

| 组件 | 用途 |
|---|---|
| `Button` | `variant`: primary/secondary/ghost/danger/quiet · `size`: sm/md/lg/icon · `asChild` |
| `Badge` | 状态。`tone`: neutral/signal/live/warn/alert/outline · `dot` · `pulse` |
| `Panel` / `PanelHeader` / `SectionTitle` | 区域。表头是细线横条，不是内边距盒子 |
| `Readout` / `ReadoutStrip` / `ReadoutCell` | 单个测量值。仪器条：并排读数 + 细线分隔 |
| `Table` / `THead` / `TH` / `TBody` / `TR` / `TD` / `TDNum` / `TableWrap` | 数据表。**只有行线，没有单元格边框** |
| `Input` / `Textarea` / `Fieldset` | 表单 |
| `Switch` | 开关（Radix 承载键盘与 ARIA） |
| `Tabs` / `TabsList` / `TabsTrigger` / `TabsContent` | 下划线式标签页 |
| `Tooltip` / `TooltipProvider` | 提示 |
| `Sheet` | 右侧详情抽屉（Radix Dialog） |
| `LoadingState` / `ErrorState` / `EmptyState` | 三种状态，全局一致 |
| `Sparkline` | 行内趋势，手绘 SVG，不引图表库 |

**Radix 负责行为，本仓库负责外观**——这就是"用可复用的、安全的，不自己造轮子"的落点。

图表：小型内联趋势用 `Sparkline`；需要坐标轴/图例/交互的用 **ECharts**（`echarts`）。

## 布局

```
┌────┬──────────────────────────────────────────────┐
│ 轨 │ 顶栏：位置 · 实例状态 · 语言                 │
│ 道 ├──────────────────────────────────────────────┤
│    │                                              │
│ 图 │  内容区（最大宽度流式，12 列基线网格）        │
│ 标 │                                              │
│ +  │                                              │
│ 标 │                                              │
│ 签 │                                              │
└────┴──────────────────────────────────────────────┘
```

- 左轨道：图标 + 短标签，可折叠
- 顶栏：当前页位置、实例健康、语言
- 内容区：**左对齐**，行宽不超过约 80 字符的文本块
- 分区之间用细线，不用间距堆叠

## 写作

界面文字是设计内容，不是装饰。

- **主动语态**。按钮说"保存更改"，就产出"已保存"。
- **按用户理解命名**，不按系统实现命名。
- **空状态是邀请**，不是情绪。失败状态**说明发生了什么、怎么修**，不道歉、不含糊。
- **句首大写**，不用全大写标签。
- 每个元素只做一件事。

## 禁止（这些是"生成感"的破绽）

- 卡片套卡片、一刀切圆角、统一柔和阴影
- 渐变装饰、彩色洗底
- 每个标题上方加全大写小标签
- 用 `·` 拼接元信息串
- 给链接和按钮无意义地加 `→`
- 把 `text-ink` 换成"高级感"的 `#0B0B0B`
- 无用户触发的动画（每区块淡入上滑、每卡片悬停位移）

## 动效

只在**回答用户操作**时动（打开、展开、确认），并且要显示"什么变了"。加载序列只保留**一个**编排好的瞬间，不要散落的特效。

## 质量底线（不是特性，是底线）

响应式到移动端 · 键盘焦点可见 · 尊重 `prefers-reduced-motion` · 颜色对比达标
