# Security Policy

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/mycatxl/Prism/security/advisories/new),
not in public issues. Include the version (`prism --version`), configuration
that matters, and steps to reproduce.

Only the latest release receives fixes. Implemented controls and known
limitations are documented in [docs/SECURITY.md](docs/SECURITY.md).
